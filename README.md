# Voxxer

Expo + TypeScript starter skeleton with a simple navigation flow that connects the
Sign In → Servers → Channels → Chat screens. Each screen currently renders
placeholder content so the navigation stack can be exercised end-to-end.

## Getting started

Install dependencies and start the Expo development server:

```bash
npm install
npm run start
```

The Expo CLI will guide you through launching the experience on iOS, Android or
web. The stack navigator is already configured to transition between the four
screens using the buttons provided on each view.
